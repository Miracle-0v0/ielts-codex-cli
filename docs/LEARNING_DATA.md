# 学习记录、迁移与恢复

本文说明 `1.0.0` 的学习规则和格式 3 数据。版本范围与发布流程见 [1.0 说明](1.0_PLAN.md)。

## 如何理解进度

- **已接触**：至少保存过一次词卡评分，不表示已经记住。
- **本次表现**：无提示首次回答、提示后回答、本组重练分别显示。认义来自自评，拼写和语境按明确答案判定。
- **稳定复习**：按认义、拼写、语境分别统计。同能力连续至少三次跨日、无提示的 Good/Easy，最近一次距上次记录练习至少七天。首次详细记录用于建立起点，本组重练不增加通过次数；错误、Hard 或提示中断该能力的连续通过。
- **尚未验证**：没有相应能力的有效练习记录，不从其他能力的通过推断。

认义、拼写和语境有独立的到期安排。认义答对不会推迟拼写任务，语境通过也不会代替其他能力。游戏另存表现；操作中断不当作语言错误，也不会制造核心复习积压。游戏不进入独立答题表现或稳定复习判定。

语境通过仅表示固定选项题的表现，不代表自由造句或目标词的全部用法已掌握。这些是项目规则，不是雅思官方评分，也不是对记忆能力的测量。旧累计数量不会被转换成虚构的跨日、无提示通过证据。

## Again 与答案规则

`/learn`、`/review`、`/quiz` 和 `/context` 的 Again 会回到本组队列。有其他卡片时隔两张再出现，剩余不足时放到队尾；每词每组最多三次。仍失败的能力保持到期，可从 `/study` 或 `/mistakes practice` 继续。

重学成功先安排次日复习。同日重复、到期前提前练习不增加长期间隔。Hard 不增加成功重复次数；提示后评分最高为 Hard。日期以本机为准。

拼写只忽略首尾空白和大小写。词内空格、数字、标点及连字符参与判定；其他合法答案由 `accepted_answers` 明确列出，相似度只提供反馈。语境题接受正确选项编号或选项完整文本，不对开放造句判分；不在选项内的输入会要求重新选择，而非直接当作语言错误。

## 每日计划与错项

`/study [5–60分钟]` 首次询问时间、薄弱项和内容包，优先安排到期任务，再安排新词与未验证能力。时间是任务预算，不是计时评分。积压时减少新词；至少三天没有学习记录时，恢复计划最多安排十项初始任务并暂缓新词。一般计划最多三十项初始任务，重练也有整组上限。

每次已完成回答与计划位置在一次保存中写入。输入 `q` 或遇到输入结束时，已完成记录和剩余任务保留；下次 `/study` 继续同一计划。输入 `s` 跳过只推进计划，不伪造回答。`/study new [分钟]` 重新安排未答任务，保留已有练习记录。切换内容包不改动正在进行的计划。

`/mistakes` 展示待练错项和相应词条的各能力最近表现。可按 `recall`、`spelling`、`context` 筛选，或用 `/mistakes practice spelling` 等命令重点练习。没有个人语境题的词保持语境尚未验证，不会自动生成答案。

## 数据位置与格式

默认目录是 `~/.ielts-codex`，可用 `--data-dir` 或 `IELTS_CODEX_HOME` 指定其他位置。

```text
.ielts-codex/
├── progress.json                 卡片、分能力安排、设置、每日汇总与逐次记录
│                                个人词库、导入历史和可继续的每日计划
├── .progress.lock                写入时使用的系统锁文件
├── backups/                      自动、手动和迁移前备份
├── game.json                     宠物和音乐偏好
├── oewn_overlay.json             可选外部词典参考
├── oewn_reference_rollback.json   最近一次词典更新前的参考快照
└── cache/                        词典预览等临时工作目录
```

进度格式版本为 3，与程序版本分别管理。逐次记录包括词条 ID、题型、日期、带时区时间、评分、是否答对、提示级别、重练、练习间隔、输入、错误类型，以及适用时的题目 ID 和方向帮助。计划位置单独保存在同一文件的每日计划中，与该次回答一起提交。

个人词库和导入历史随进度一起备份。游戏偏好与外部词典参考是独立文件，因此完整迁移或异地备份应复制整个数据目录。

## 从 0.6.10 或格式 2 升级

直接使用原数据目录，无需删除 `progress.json`。

1. 读取格式 1 或 2 时，保留原卡片、设置、每日汇总、创建时间和已有详细记录；加载不会改写原文件。
2. 首次成功保存前，将旧文件完整原始字节保存为 `backups/migration-v1-*.json` 或 `migration-v2-*.json`。不是重新生成一份近似数据。
3. 保存格式 3，将旧词条映射到稳定 ID。旧共享卡片的安排放入认义能力，不能凭空推造独立拼写或语境复习安排；这些能力从实际新练习开始。已有详细历史继续保留。
4. 新回答与计划位置一同保存；迁移或保存失败时不会把旧文件当成空进度覆盖。不支持的未来格式或损坏文件会明确报错。

旧程序不能安全使用新格式。需要回到旧版时，先用 1.0 版本恢复对应迁移前备份，再退出并切换旧程序。新格式下的练习留在恢复前备份中，不会自动合并进旧格式。不要同时让旧程序和新版写同一目录。

## 备份与恢复

```text
/backup
/backups
/restore manual-实际时间和编号.json
```

主文件损坏、无法进入界面时，可在终端运行：

```text
ielts backups
ielts restore manual-实际时间和编号.json
```

使用自定义目录时，加相同的 `--data-dir`：

```text
ielts backups --data-dir ./my-progress
ielts restore manual-实际时间和编号.json --data-dir ./my-progress
```

使用实际列出的备份名。恢复前检查备份，并将当前文件另存为 `before-restore-*.json`；当前文件即使损坏也保留副本。

覆盖进度前自动备份，保留最近十份 `progress-*.json`。手动、迁移和恢复前备份不自动清理。同设备备份不防设备丢失；可另存整个数据目录。

两个新版实例同时使用时，系统锁和保存前快照比较会拒绝过期写入。冲突回答会明确提示未写入，重新打开读取最新进度后再答；已有记录不被覆盖。`.progress.lock` 文件保留是正常现象，退出后系统释放锁，无需手动删除。
