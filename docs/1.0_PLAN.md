# IELTS Codex 1.0 范围与发布流程

1.0 面向中文学习者，提供离线优先的雅思词汇与表达训练：认识单词、准确拼写、理解语境，并在隔天复习中验证记忆。保留终端交互、无账号、零运行时依赖和像素游戏。

词汇记录不换算为雅思分数。完整模考、作文评分、语音评分和多设备同步不属于 1.0 范围。

## 功能范围

| 领域 | 1.0 提供的能力 |
| --- | --- |
| 学习与进度 | Again 重练队列、保守调度、严格拼写、逐次表现、按能力的稳定复习 |
| 个人词库 | 稳定 ID、多义项、CSV/JSON 预览导入与撤销、待补全、内容包和用法字段 |
| 每日训练 | 可继续的 `/study`、积压与恢复计划、认义/拼写/语境独立安排、分能力 `/mistakes` |
| 内容 | 72 个词条、9 个话题、24 道原创固定选项语境题，以及可编辑的导入示例 |
| 数据与更新 | 格式 3 迁移、原始备份、并发保护、恢复入口、分开的程序更新与词典参考更新 |

## 验证依据

真实主机已完成自动测试与终端交互检查：Windows / Python 3.13.9 使用 ConPTY，Ubuntu / Python 3.12.13 使用 POSIX PTY，Mac（Darwin 25.6、arm64）/ Python 3.10.20 使用 POSIX PTY。测试覆盖键盘交互、学习重练、退出继续、导入和恢复等实际流程。

[正式 v1.0.0 标签的三平台 CI](https://github.com/Miracle-0v0/ielts-codex-cli/actions/runs/36012363083) 已全部通过：Windows、Ubuntu、macOS 15 Intel 均实际运行 Python 3.10，完成行为测试、安装包检查、真实终端输入以及启动器和安装检查。

安装包包含全部运行模块和 JSON 内容。迁移、恢复与终端检查使用临时合成进度，没有改写用户学习目录。自动检查和终端测试不等于词条或题目完成人工内容审校。

## 正式发布流程

1. `pyproject.toml` 与运行时版本一致，正式版为 `1.0.0`；发布提交位于官方 `main` 历史中。
2. 推送 `v1.0.0` 标签后，工作流重新运行三平台 Python 3.10 测试、原生终端检查和安装包验证。
3. 仅当三个平台全部成功，发布任务才核对标签、提交和 wheel 的版本身份，并使用同次运行测试过的 Ubuntu wheel 创建 GitHub Release。
4. 分支推送只做验证，不发布。任一步失败都会阻止发布，不能用本地成功代替标签工作流的结果。

[v1.0.0 正式版](https://github.com/Miracle-0v0/ielts-codex-cli/releases/tag/v1.0.0) 已于 2026-09-24 发布，包含经过该次标签工作流验证的 wheel。

## 学习与数据规则

- Again 在本组稍后出现，每词最多三次；每日计划另有整组上限。
- 同日反复、提前练习和提示后完成不反复拉长间隔；重学成功先安排次日复习。
- 拼写仅忽略首尾空白和大小写，其他合法答案显式列出。
- 认义、拼写和语境分别安排到期，记录提示、重练、错误类型和时间；不从旧累计次数推造历史证据。
- 稳定复习要求同能力连续至少三次跨日、无提示 Good/Easy，最近一次练习间隔至少七天；首次详细记录建立起点，错误、Hard 或提示中断连续通过。
- 格式 1/2 首次保存为格式 3 之前完整备份原始文件，保留旧设置、卡片和已有历史。旧共享安排进入认义，不伪造其他能力安排。
- 系统锁和快照比较阻止过期实例覆盖记录；游戏操作失败不当作语言错误或核心复习积压。

迁移与恢复步骤见 [学习记录](LEARNING_DATA.md)。

## 内容与后续范围

24 道原创固定选项题包括 13 道词形和 11 道搭配。词条使用核心／进阶／拓展等编辑标签，不对应官方 Band。个人词库让用户把真实备考中遇到的词加入训练，未补全条目不判分。

题目经过自动规则检查和代理阅读检查，不声称完成人工或外部审校。语境通过只表示固定选项题表现，不代表自由造句或掌握目标词的全部用法。后续将根据内容检查与用户反馈扩充词条。

程序、内置内容和外部词典版本分开。OEWN 仅作有来源的参考，预览并确认后安装，支持最近一次更新回退，不覆盖教学释义、个人词条或题目。

可选本地发音与听写、AI 造句反馈、段落改写、更丰富的游戏和多设备同步留待后续。AI 不作为核心依赖；没有音频不评价发音，未经校准的反馈不称为官方雅思分数。
