# IELTS Codex 1.0 更新计划

1.0 面向中文学习者，提供离线优先的雅思词汇与表达训练：认识单词、准确拼写、理解语境，并在隔天复习中验证记忆。保留终端交互、无账号、零运行时依赖和像素游戏。

## 学习与数据规则

- Again 在本组稍后出现，每词最多三次；每日计划另有整组上限。
- 同日反复、提前练习和提示后完成不反复拉长间隔；重学成功先安排次日复习。
- 拼写仅忽略首尾空白和大小写，其他合法答案显式列出。
- 认义、拼写和语境分别安排到期，记录提示、重练、错误类型和时间；不从旧累计次数推造历史证据。
- 稳定复习要求同能力连续至少三次跨日、无提示 Good/Easy，最近一次练习间隔至少七天；首次详细记录建立起点，错误、Hard 或提示中断连续通过。
- 格式 1/2 首次保存为格式 3 之前完整备份原始文件，保留旧设置、卡片和已有历史。旧共享安排进入认义，不伪造其他能力安排。
- 系统锁和快照比较阻止过期实例覆盖记录；游戏操作失败不当作语言错误或核心复习积压。

迁移与恢复步骤见 [学习记录](LEARNING_DATA.md)。

## 内容和更新范围

内置 72 词覆盖 9 个话题，24 道原创固定选项题包括 13 道词形和 11 道搭配。词条使用核心／进阶／拓展等编辑标签，不对应官方 Band。个人词库让用户把真实备考中遇到的词加入训练，未补全条目不判分。

题目经过自动规则检查和代理阅读检查，不声称完成人工或外部审校。语境通过只表示固定选项题表现，不代表自由造句或掌握目标词的全部用法。300～500 词是后续内容目标，不是当前数量或发布凑数要求。

程序、内置内容和外部词典版本分开。OEWN 仅作有来源的参考，预览并确认后安装，支持最近一次更新回退，不覆盖教学释义、个人词条或题目。真实联网更新本次未执行。
