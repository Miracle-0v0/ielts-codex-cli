IELTS Codex 1.0 将离线背词、拼写与语境练习连成一条可以每天继续的学习路线。核心使用仍然只依赖 Python 标准库，无账号，无 API Key。

## 每天打开即可开始

- `/study 20` 安排到期复习、新词和未验证能力；中途退出后继续原计划。
- 复习积压时减少新词，隔几天回来时使用较短的恢复计划。
- Again 在本组稍后重练，有次数上限；同日重复和提示后答对不会快速拉长复习间隔。

## 把自己的词带进来

- CSV / JSON 导入提供预览、错误说明、重复检查和确认；支持撤销导入。
- `/add` 收集待补全词条，`/decks` 选择内容包。同一拼写可以保存不同义项。
- 内置 72 个词条、9 个话题和 24 道原创语境选择题，支持搭配与词形练习。

## 看清自己还需要练什么

- 认义、拼写和语境分别安排复习，分别保存表现。
- `/mistakes` 按能力查看和练习错项；无提示、提示后完成和本组重练分开记录。
- “稳定复习”依据跨日、无提示的连续表现，不把累计次数或某一种能力当作全部掌握。
- 拼写只忽略大小写和首尾空白，其他拼写变体需要词条明确允许。

## 保留进度，分开管理更新

从 0.6.10 或格式 2 升级无需删除学习记录。首次保存为格式 3 前，完整备份原始进度文件；旧设置、卡片与已有历史保留。增加并发写入冲突保护、自动及手动备份、恢复入口。

`/update` 默认离线展示版本与选项。`/update program` 管理程序更新，`/update dictionary` 预览并确认外部词典参考，支持最近一次更新回退。OEWN 参考不会覆盖教学释义、个人词条或训练答案。

## 安装

需要 Python 3.10+。下载本页 wheel 后，在文件所在目录运行：

```text
python -m pip install ./ielts_codex-1.0.0-py3-none-any.whl
ielts --version
ielts
```

源码启动与安装入口保持不变：Windows 使用 `run.bat` / `install.bat`，macOS 和 Linux 使用 `./run.sh` / `./install.sh`。卸载程序不会自动删除学习记录；完整备份可复制整个数据目录。

## 使用范围

这是独立的词汇与表达辅助训练器，不是完整雅思模考，不提供官方分数或提分保证。语境表现只针对固定选项题，不代表自由造句或已掌握一个词的全部用法。内容未声称完成人工或外部审校。

像素游戏和可选宠物功能继续保留。自由造句反馈、完整作文、语音评分与多设备同步留待后续。
